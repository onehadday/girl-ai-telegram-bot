# ШІ для переписки

Локальний помічник для знайомств у Telegram або будь-якому чаті. Ти вставляєш переписку або опис ситуації, а застосунок пропонує готове повідомлення, альтернативи і коротко пояснює, чого краще не писати.

## Як запустити

1. Скопіюй `.env.example` у `.env`.
2. Для безкоштовного старту додай `GEMINI_API_KEY`.
   - Ключ можна створити в Google AI Studio.
   - Модель за замовчуванням: `gemini-3.5-flash`.
3. Альтернатива: додай `OPENROUTER_API_KEY`, тоді застосунок використає `openrouter/free`.
4. Запусти:

```powershell
python server.py
```

5. Відкрий:

```text
http://127.0.0.1:8000
```

Без API-ключа застосунок працює в простому локальному режимі з базовими підказками. З ключем Gemini, OpenRouter або OpenAI він генерує персональні відповіді під конкретну переписку.

Пріоритет ключів такий:

1. `GEMINI_API_KEY`
2. `OPENROUTER_API_KEY`
3. `OPENAI_API_KEY`
4. Локальний запасний режим

## Як користуватись

- Вибери ситуацію: продовжити розмову, глухий кут, запросити на зустріч тощо.
- Встав останні повідомлення або коротко опиши, що сталося.
- Напиши свою ціль і бажаний стиль.
- Натисни "Підібрати відповідь".

Помічник спеціально налаштований не радити тиск, маніпуляції або десятки повідомлень підряд.

## Telegram-бот

1. У Telegram відкрий `@BotFather`.
2. Напиши `/newbot` і створи бота.
3. Скопіюй токен.
4. У `.env` додай:

```text
TELEGRAM_BOT_TOKEN=твій_токен_від_BotFather
```

5. Запусти:

```powershell
python telegram_bot.py
```

Або відкрий `start_bot.bat`.

Після запуску напиши своєму боту `/start`. Далі можна кидати йому переписку або короткий опис ситуації.

Команди стилю:

```text
/mode normal
/mode bydlo
/style коротко, без пафосу, трохи нагло
/phrases та ну нафіг; погнали на каву; не душню
/avoid сонечко; красуня; чого мовчиш
/settings
```

`/mode bydlo` робить відповіді грубішими і може додавати лайку, але бот все одно не буде радити принижувати дівчину, тиснути або писати агресивно.

Щоб ботом користувався тільки ти:

1. Напиши боту `/id`.
2. Скопіюй свій Telegram ID.
3. Додай у `.env`:

```text
TELEGRAM_ALLOWED_USER_ID=твій_id
```

## Хостинг бота

Для хостингу використовуй webhook-версію:

```powershell
python bot_webhook.py
```

На Render або схожому сервісі треба створити Web Service і додати змінні:

```text
TELEGRAM_BOT_TOKEN=токен_від_BotFather
TELEGRAM_ALLOWED_USER_ID=824778488
TELEGRAM_WEBHOOK_SECRET=довгий_секретний_рядок
GEMINI_API_KEY=твій_gemini_ключ
GEMINI_MODEL=gemini-3.5-flash
PUBLIC_URL=https://твій-сервіс.onrender.com
```

Start command:

```text
python bot_webhook.py
```

Після запуску сервіс сам поставить Telegram webhook на адресу:

```text
PUBLIC_URL/telegram/TELEGRAM_WEBHOOK_SECRET
```

На хостингу головна сторінка `PUBLIC_URL` відкриває веб-версію сервісу:

- веб-чат замість Telegram-чату;
- сценарії з бота у вигляді карток;
- налаштування стилю, фраз і фраз-табу;
- реєстрація та вхід;
- окрема історія переписки для кожного профілю;
- розпізнавання скріншотів переписки через Gemini;
- адмін-історія повідомлень для модерації;
- тариф-сторінка як заготовка, бо в поточному боті ще немає реальної оплати.

Перший зареєстрований користувач автоматично стає адміном. Щоб не ризикувати на публічному хостингу, можна додати змінну:

```text
ADMIN_EMAIL=твій_email
```

Тоді користувач із цим email теж буде адміном після реєстрації.

Як користуватись реєстрацією:

1. Відкрий сайт.
2. Перейди в `Кабінет`.
3. Зареєструй акаунт.
4. Без входу сайт не дозволяє надсилати повідомлення в чат.
5. Для модерації відкрий `Історія`: спочатку обери юзера, потім дивись тільки його історію.

Паролі не зберігаються відкритим текстом. Їх не можна переглянути назад, зате користувач може змінити свій пароль у кабінеті, а адмін може скинути пароль користувачу в розділі `Історія`.

Для пам'яті переписки створи профіль співрозмовниці, обери його в чаті та вкажи,
хто написав нове повідомлення. Сайт збереже повідомлення в базі й підставить
останні 40 повідомлень під час наступної генерації. Скріншот можна додати
кнопкою `Додати скріншот`; перед відправкою варто перевірити розпізнаний текст.

У Telegram можна переслати боту повідомлення або скріншот. Для ручної окремої
переписки використовуй `/chat Ім'я`, `/her текст`, `/me текст`, `/history` і
`/clear`. Кожен згенерований варіант надсилається окремим повідомленням із
кнопкою `Копіювати`. Звичайний Telegram-бот не має права самостійно читати
приватні чати користувача за ID, тому нові повідомлення потрібно пересилати боту.

Зараз база даних зберігається в SQLite-файлі. Для нормального продакшну на Render краще підключити зовнішню базу, наприклад Supabase, бо безкоштовний Render може втрачати локальні файли після перезапусків або деплоїв.

## Supabase база

Якщо додати `DATABASE_URL`, застосунок автоматично використовує Supabase/Postgres замість локального SQLite.

1. У Supabase створи Project.
2. Відкрий `Project Settings`.
3. Відкрий `Database`.
4. Знайди `Connection string`.
5. Обери URI-формат.
6. Скопіюй рядок підключення і заміни `[YOUR-PASSWORD]` на пароль бази.
7. У Render додай Environment Variable:

```text
DATABASE_URL=postgresql://...
```

8. Зроби `Manual Deploy -> Deploy latest commit`.

Після старту сайт сам створить таблиці:

- `users`
- `sessions`
- `interactions`
- `conversation_messages`

Якщо хочеш гарантовано зробити свій акаунт адміном, додай у Render:

```text
ADMIN_EMAIL=твій_email
```
